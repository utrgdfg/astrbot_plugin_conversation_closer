# Security Policy

## Supported versions

Security fixes are provided for the latest released minor version until the project reaches 1.0.0.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not include API
keys, tokens, cookies, complete private conversations, or other secrets in a public issue.

The plugin does not implement its own network client. Conversation excerpts are sent only through
the AstrBot LLM Provider explicitly selected by the administrator.
